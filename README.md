
# CGPA Calculator - V2

This is the improved version of my CGPA Calculator.

After testing my first version, I identified several problems involving
edge cases, input validation, and the overall robustness of the program.

I used what I learned from the first attempt to improve the program.

## Improvements from V1

- Added better input validation (2 ways)
- Handled additional edge cases
- Improved the calculation logic
- Improved the structure and readability of the code
- Fixed issues discovered while testing

## What I Learned

This project taught me that getting a program to work is not the same
as making it robust. Testing different inputs helped me identify
problems that I did not notice during my initial implementation.

This version represents my progress from my first attempt and the
knowledge I gained throughout the process.
